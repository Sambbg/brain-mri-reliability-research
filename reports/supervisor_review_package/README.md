# Supervisor Review Package

## Purpose

This folder contains a clean supervisor-review version of the current MSc research project.

## Main Files

1. `01_manuscript_draft_v1.md`  
   Full manuscript draft with citation placeholders.

2. `02_supervisor_update_report.md`  
   High-level progress report for supervisor review.

3. `03_submission_readiness_checklist.md`  
   Clear separation between MSc-readiness and journal-submission readiness.

4. `04_manuscript_statements.md`  
   Draft data availability, code availability, ethics, AI-use, clinical-use, conflict-of-interest, and funding statements.

5. `05_reference_list_placeholders.md`  
   Placeholder reference list mapped to manuscript `REF-*` citation IDs.

## Tables

The `tables/` folder contains manuscript Tables 1–5 in markdown and CSV format.

## Figures

The `figures/` folder contains manuscript Figures 1–6 in PNG and PDF format.

## Audits

The `audits/` folder contains:

- Citation integrity audit.
- Manuscript consistency audit.
- Final manuscript readiness audit.

## Current Status

This package is suitable for MSc supervisor review.

It is not yet a final journal-submission package because citation placeholders still need conversion into the final required reference style, and all references must be manually verified before submission.
