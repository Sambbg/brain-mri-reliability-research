# Brain MRI Reliability Research

## Research Question

This project investigates the reliability of deep learning models for brain MRI tumour classification, with emphasis on model calibration, uncertainty estimation, robustness, and cross-dataset generalisation.

The central research question is:

> How reliable are deep learning-based brain MRI tumour classification models when evaluated beyond standard accuracy, using calibration, uncertainty, and external validation metrics?

This project does not treat high classification accuracy alone as sufficient evidence of clinical reliability.
